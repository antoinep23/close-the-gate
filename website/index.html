The power of the cloud, the privacy of local storage.

Close the Gate gives you the scalability and availability of AWS S3 without ever compromising on privacy. Your files are encrypted before they leave your machine. The cloud stores only ciphertext it can never read.

Built for privacy

Every design decision prioritizes your data sovereignty. No compromises.

Client-side encryption

All cryptographic operations happen on your machine. Files are encrypted with AES-256-GCM before upload. The cloud only stores ciphertext.

You own the keys

Keys are generated locally and stored on your machine with restricted permissions (mode 0600). They never leave your environment.

Zero-Knowledge

AWS S3 and DynamoDB never have access to raw data or keys. File names are hashed with HMAC SHA-256. Metadata stores only what's necessary.

Key rotation

Rotate encryption keys per-file, in batch, or trigger an emergency rotation for all files. Auto-rotation with configurable intervals.

In-memory preview

Preview encrypted files without ever writing to disk. Decrypted on the fly in memory, then discarded. Maximum privacy.

Web UI + CLI + SDK

Use the Google Drive-style web interface, the command-line tool, or import the TypeScript SDK directly into your own code.

How it works

A simple pipeline that keeps your data safe at every step.

1

Generate a key

A random AES-256 key is generated locally using Node.js crypto. It's saved to your disk with restricted file permissions. The key never touches a network.

2

Encrypt locally

Your file is read, encrypted with AES-256-GCM using a random IV, and the file name is hashed with HMAC SHA-256. The result is a binary payload: IV + Ciphertext.

3

Upload to S3

The encrypted payload is uploaded to your own S3 bucket under the hashed name. The bucket only ever contains unreadable ciphertext with opaque file names.

4

Download & decrypt

To access a file, the payload is fetched from S3, decrypted locally with your key, and either saved or previewed in-memory. The cloud never processes plaintext.
